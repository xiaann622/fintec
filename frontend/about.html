About this System
What it does, and how it's built.

M-Pesa Transaction Intelligence

This platform turns raw M-Pesa statements — CSV exports, PDFs, or scanned/photographed paper statements — into a structured, searchable ledger with automatic label, classification and category tagging. Beyond simple categorization, it gives finance teams a full behavioural view of a customer or business: when they transact, how weekday activity compares to weekends, how spending moves through the month, and where confidence in the model is low enough to warrant a manual look. It's built to help finance companies extract transactions and understand transaction behaviour, accelerating decisions like creditworthiness checks, KYC reviews and fraud triage.

Ingestion pipeline

1
CSV / Excel
Parsed directly with column auto-mapping.
2
Text-layer PDFs
Extracted with a text/table parser.
3
Scanned PDFs & photos
Rasterised and read with OCR, then pattern-matched into structured rows.

Three-stage ML pipeline

L
Label
TF-IDF text features + 12 behavioural features (time-of-day, weekday/weekend, amount bands).
C
Classification
TF-IDF + 13 features, using the predicted label as an input feature.
K
Category
TF-IDF + 14 features, using both the predicted label and classification.

🔒 Security

JWT-based authentication, hashed passwords, and role-based access. All API calls require a valid session token.

🏗️ Architecture

FastAPI backend, Postgres 14 database, HTML/CSS/JS frontend, and a companion Streamlit analytics app — all deployable independently.

📈 Built for finance teams

Bulk statement ingestion and instant behavioural analytics are designed to accelerate decisions that used to take manual review.
